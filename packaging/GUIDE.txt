AdventureSquad —— 安装与开发指引
==================================================

一、怎么玩
--------------------------------------------------

桌面双击「AdventureSquad」图标即可。

它会弹出一个黑色命令行窗口（这是本地服务器，别关），同时浏览器会自动打开游戏。
关掉那个命令行窗口就等于退出游戏。

首次进入是角色选择界面，三个角色：

  骑 士   5 点血，近战范围斩击，伤害 x3
  法 师   3 点血，法球落点爆炸，伤害 x4.5
  游 侠   4 点血，枪械射击，有弹匣

三种模式：

  经 典  8 间房的随机迷宫，每关清光所有敌人后从出口进下一关，每关一个 Boss
  挑 战  开战前先在选牌库里挑 3 张强化，然后打虚空祭司（纯 Boss 战）
  无 尽  没有出口，一直打下去，死了才算结束

操作：

  W A S D / 方向键   移动
  鼠标               瞄准
  鼠标左键           攻击
  Shift / 空格       冲刺
  1 2 3              游侠切换武器（剑 / 斧 / 魔杖）
  P                   打开设置（音量、震屏、伤害数字）
  R                   阵亡后回到主菜单

左上角会显示本局的「种子」。同一个种子能完整复现同一局（地图和抽卡都一样），
把种子发给朋友就能比成绩。


二、为什么需要 Node.js 或 Python
--------------------------------------------------

游戏资源是用 Cocos 的 resources.load 从文件里读的，浏览器的 file:// 协议不允许
读本地文件，所以必须起一个本地 http 服务。启动器会依次尝试：

  Node.js   https://nodejs.org
  Python    https://www.python.org   （Windows 上一般是 py -m http.server）

两个都没有的话会提示装一个 —— 装完再双击就能玩。
如果你只想玩、不打算改代码，也可以不装：本安装包里的 Source 目录不含这些依赖，
但游戏本体本身是打包好的，不需要任何编译环境。


三、怎么用源码继续开发
--------------------------------------------------

需要 Cocos Creator 3.8.8：https://www.cocos.com/creator

  1. 打开 Cocos Creator -> 项目 -> 添加 -> 选择本目录下的 Source 文件夹
     （或者用命令行： CocosCreator.exe --project <Source 路径>）
  2. 等资源库导入完，打开 assets/scenes/main.scene
  3. 点工具栏的播放按钮就能在编辑器里跑

两个代码文件：

  assets/scripts/Core.ts    地图生成、瓦片碰撞、配色常量
  assets/scripts/Game.ts    玩法全部在这里（角色、敌人、Boss、模式、UI）
  assets/scripts/Audio.ts   音效和 BGM
  assets/scripts/DamageText.ts  伤害飘字

Source 目录里还带了 tools/ 目录，里面是开发期用的回归测试脚本
（见 tools/README.md）。跑测试需要先构建一次，再起 tools/serve.js，
然后用无头 Chrome 连上去。


四、目录说明
--------------------------------------------------

  Game/            游戏本体（已构建好的网页版，双击 play-game.bat 运行）
  Source/          项目源码，用 Cocos Creator 打开这个文件夹
  安装与开发指引.txt  就是本文件
  uninstall.cmd    卸载脚本（桌面也有快捷方式）
