# AdventureSquad

一个用 Cocos Creator 3.8.8 做的 2D 俯视角 roguelike 射击小游戏，玩法参考《元气骑士》。
没有预制体，场景里只有一个 Canvas 和一个 Game 组件，其余（角色、怪物、子弹、地图、HUD、菜单）
全部在运行时用代码生成。

## 玩法

### 三种模式

| 模式 | 内容 |
|---|---|
| **经典** | 8 间房的随机迷宫，每关清光所有敌人后从出口进下一关，每关一个 Boss。固定种子，同一张 1 号地图 |
| **挑战** | 开战前在选牌库里挑 3 张强化，然后打虚空祭司（纯 Boss 战，三个阶段 12 个招式） |
| **无尽** | 没有出口，清光一关直接进下一关，敌人和 Boss 随关卡变强，死了才算结束。每局随机种子 |

种子显示在左上角，同一个种子能完整复现同一局（地图、抽卡顺序都一样），可以拿去和别人比成绩。

### 三个角色

| 角色 | 攻击 | 特点 |
|---|---|---|
| 骑士 | 身前一个圆形范围的斩击，范围内全部敌人受伤 | 冷却 0.5 秒，伤害 ×3，生命 5 |
| 法师 | 法球飞出 3 格后在落点爆炸，爆炸范围内全部敌人受伤 | 充能 1.5 秒，伤害 ×4.5，生命 3 |
| 游侠 | 子弹射击，三把枪可切换（剑 / 斧 / 魔杖） | 有弹匣，伤害 ×1，生命 4 |

### 敌人和 Boss

- 史莱姆（贴脸冲）、法师（放弹保持距离）、幽灵（忽快忽慢）、壮汉（第 5 关起，撞人掉 2 血）
- 每关一个 Boss，四个造型轮换（霜冠领主 / 炎冠君王 / 古木守卫 / 角魔将军），循环时再整体调色
- Boss 房要等全图小怪清零才开门，出口就在 Boss 房里
- 虚空祭司（挑战模式）：血量三段变化对应三个阶段，每阶段 4 个招式，同阶段等概率抽取

### 强化

每关三选一，共 22 张，分三档品质（**金框=传说 / 紫框=史诗 / 银框=稀有**），
牌库按品质从高到低排列。

- 传说：暴击、暴伤、处决、狂暴、复仇
- 史诗：铁壁、贯穿、散射、弹匣、弹跳、疾影、磁铁、嗜血、反伤
- 稀有：力量、急速、迅捷、体魄、疾射、坚韧、收割、吸血

几个说明：

- **贯穿 / 散射 / 弹跳** 对三个职业含义不同：骑士是剑气范围变大、法师是爆炸范围变大、游侠才是子弹相关
- **弹跳**只给骑士以外的职业（弹墙没有意义）
- **反伤**只给骑士
- **复仇**：每击杀 20 个敌人获得一次原地复活（最多攒 2 次），**拿上之后才开始计数**
- **狂暴**：血量低于 1/3 时伤害翻倍（主角会发红光）
- 挑战模式用同一批牌，但数值更高

### 地图

每关生成一张 84×30 格（2688×960 像素）的地图：4×2 个大格各放一间大小随机的房间，
用 2 格宽的走廊串起来（随机生成树 + 几条额外环路）。

- 走廊走「房间 → 格子间隙 → 房间」，房间之间恒定留 2 格空地，所以走廊可以拐弯，
  两间房位置再随机也连得上，也不会横穿房间内部
- 每个房间至少 2 扇门（只有一扇门是死胡同）
- 进到还有怪的房间，门会锁上（显示暗红），清光后自动打开
- 敌人从关卡开始就都在（每间房 2 只起），没进过的房间里原地待命
- 通关条件 = 击杀地图上所有敌人；全清后出口开启，走进去进下一关
- 右上角小地图画真实布局，并标出每扇门能不能过（绿点=通，红点=锁着）

## 实现逻辑

代码只有两个文件：`assets/scripts/Core.ts`（地图与碰撞）和 `assets/scripts/Game.ts`（玩法）。

**种子化**：全局随机数换成 mulberry32，每关的随机源由 `runSeed + 关卡数×1000003` 派生，
所以地图和抽卡都能复现。

**迷宫生成带三重自检**，都是生成完立刻跑一遍，有问题就地修：

1. 连通性 —— 从起点洪水填充，有房间走不到就补一条长廊
2. 死胡同 —— 只有一扇门的房间自动再接一条
3. Boss 房不是必经之路 —— Boss 房要等小怪清零才开，如果某个房间只能穿过 Boss 房才到，
   那间房的怪就永远打不到，整局死锁，所以要去掉 Boss 房再检查一遍连通性

另外道具不会生成在紧挨着房门的位置（会把门的通道堵死），出口也不会放在房间角落（玩家挤不进去）。

**寻路**：从主角所在格做一次 BFS 算出全场距离场，所有敌人共用一张（比每个敌人各跑一次搜索便宜），
敌人沿距离场走。距离场每 0.2 秒或主角换格时重算一次，关着的门算实心，所以别的房间的怪会原地待命。

**敌人卡住**：圆形身体贴着箱子斜角时会卡死（身体没嵌进墙里，常规的脱困逻辑救不了）。
所以敌人有卡住检测 —— 一直靠近不了主角就改走距离场里次优的那条路绕过去。

**Boss 招式**：挑战模式的虚空祭司有一张招式表（id / 阶段 / 持续时间 / 冷却），
每阶段 4 个招式，同阶段等概率抽取。招式分「起手」和「进行中」两段，各自带一套状态机。
激光用线段距离判定，黑洞会把玩家往中心拽，落石是先画预警圈再爆炸。

**手感**：命中飘伤害数字（暴击是金色大字 + 黑描边）、震屏（射手不震）、受击顿帧。

**音频**：`AudioSys` 管音效播放池、背景音乐和音量设置（存 localStorage）。
菜单 / 战斗 / Boss 三首 BGM，进 Boss 房自动切曲。

## 技术栈

- Cocos Creator 3.8.8（TypeScript）
- 无框架、无预制体、无 npm 依赖，全部逻辑自己写
- 美术是 16×16 像素图，运行时用 `resources.load` 按路径加载
- 音频用 Cocos 的 `AudioSource`，音效池 + 单例 BGM
- 测试用 Chrome DevTools Protocol 驱动无头浏览器跑真实构建产物（见 `tools/README.md`）

## 打包发布

`packaging/` 下是打包脚本，产出一个安装程序和一个安装载荷：

```bash
node packaging/build-installer.js
```

- `AdventureSquad-Setup-<版本>.exe` —— WinForms 安装程序，用 .NET Framework 自带的 `csc.exe` 编译
  （接收方不需要装任何运行时），解压载荷到 `%LOCALAPPDATA%\AdventureSquad` 并建桌面快捷方式
- `AdventureSquad-<版本>.zip` —— 安装载荷（游戏本体 + 项目源码 + 指引）

两个文件要放在同一个目录里。安装程序是 GUI 的，会显示进度并建出
「开始游戏 / 卸载」两个桌面快捷方式。
