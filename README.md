# KnightLite —— 极简元气骑士

一个用 **Cocos Creator 3.8.8** 做的 2D 俯视角 roguelike 射击小游戏，参考《元气骑士》的玩法内核，但刻意做到最小：

- **零预制体**：场景里只有官方 2D 模板的 Canvas + 一个 `Game` 组件，角色、敌人、子弹、地图、HUD、菜单全部运行时用代码生成。
- **像素美术**：全部素材是 Kenney 的 CC0 像素包（16×16），统一 2 倍放大，瓦片 32px。
- **完整内循环**：选角色 → 探索多房间迷宫 → 打怪清房 → 三选一强化 → 找出口进下一关。

## 怎么跑

**方式一：编辑器（推荐）**

1. 打开 Cocos Dashboard → 项目 → 添加 → 选 `D:\cocos\KnightLite` 目录（或 `CocosCreator.exe --project D:\cocos\KnightLite`）。
2. 打开 `assets/scenes/main.scene`，点工具栏的 ▶️ 预览。
3. **先点一下游戏画面**，让画布获得焦点，否则键盘收不到事件（Cocos 把键盘监听挂在 canvas 上）。

**方式二：已构建好的网页版**

`build/web-mobile/web-mobile/` 是现成构建产物，起个静态服务器打开 `index.html` 即可：

```bash
cd D:\cocos\KnightLite\build\web-mobile\web-mobile
python -m http.server 8080     # 访问 http://localhost:8080
```

## 音效与手感

- **音效**：全部来自 Kenney 的 **CC0** 音效包（公共领域，可商用免署名）。命中、受击、爆炸、斩击、法球、拾取、开门、升级、菜单点击都有对应音效（23 个音效文件）。
- **背景音乐**：菜单 / 战斗 / Boss 三首循环曲，进 Boss 房会自动切曲。
- **打击感**：命中会**飘伤害数字**（暴击是金色大号）、**震屏**、受击有**顿帧**。震屏频率按职业分：**射手完全不震**（子弹太密，晃得看不清），骑士和法师每次命中都震。
- **设置菜单**：开始界面右下角「设 置」按钮，或游戏中按 **P** 打开。可以调**音乐音量 / 音效音量**（分开）、开关**震屏**、开关**伤害数字**，设置会存到本地。



### 开始界面：两个模式

先在开始界面选模式，再选职业：

| 模式 | 内容 |
|---|---|
| **经典模式** | 完整流程：8 间房的随机迷宫 → 每关一个 Boss → 三选一强化 → 下一关。**固定种子 = 20240707（1 号地图）**，每次玩都是同一张 1 号地图 |
| **挑战模式** | **纯 Boss 战**：先在**选牌库**里选好 3 张强化，再进大竞技场（中央四根柱子当掩体）打「虚空祭司」；打死 Boss 即通关 |
| **无尽模式** | **一直打下去**：和经典模式一样的 8 间房迷宫，但**没有出口** —— 清光一关（含 Boss）立刻进下一关，每关三选一强化，敌人和 Boss 随关卡数变强；死了才算结束（显示坚持到第几关 + 种子） |

**挑战模式的选牌库**（独立 UI，模仿金铲铲之战「大橘大利」的**局外构筑**）：把你自己的强化牌库**整副摊开**，**每种强化只有一张**，从中挑 **3 张**组成出战卡组 —— **不能重复选、没有刷牌**。牌库**按品质从高到低排列**，卡框颜色即品质：

| 品质 | 卡框 | 强化 |
|---|---|---|
| **传说** | 金 | 暴击、暴伤、处决、狂暴、复仇 |
| **史诗** | 紫 | 铁壁、贯穿、散射、弹匣、弹跳、疾影、磁铁、嗜血、反伤、狙神 |
| **稀有** | 银 | 力量、急速、迅捷、体魄、坚韧、收割、吸血 |

选中的卡会变绿并进到底部的 3 个卡组槽位，选满才能「开始挑战」。牌多了屏幕放不下，**用鼠标滚轮上下翻**（一次滚轮 = 一整行，始终看到整齐的几行），右侧有滚动条。

| 阶段 | 招式 |
|---|---|
| 一 | 环形弹幕 / 召唤侍从 / 黑洞吸引 / 旋转螺旋 |

> 挑战模式的招式冷却全部压过经典版：阶段一约 2.9 秒出一招、阶段二约 3.3 秒、阶段三约 4 秒 —— 打得比普通 Boss 密得多。

### 三个角色（开局点选，攻击方式完全不同）

| 角色 | 攻击方式 | 特点 |
|---|---|---|
| **骑 士** | **近战斩击**：挥出一道**月牙剑气**，初始范围约 **1.7 格**（53 像素），**范围内的敌人全部受伤（群体伤害，不分方向）** | 冷却 **0.5 秒**，右下角显示「斩 击」冷却条；**伤害 ×3**（近战有风险，所以给高倍率） |
| **法 师** | **魔法球**：放出一颗紫色法球，飞出 **3 格**后在落点**爆炸**，爆炸范围 **2 格**，范围内全部敌人受伤 | 充能 **1.5 秒**，右下角显示「充 能」进度条；**伤害 ×4.5**（骑士的 **1.5 倍**倍率） |
| **游 侠** | **子弹射击**（不变）：可按 `1`/`2`/`3` 换三把枪 | 右下角显示弹匣 `当前/上限` |

- 骑士的强化联动：「贯穿」→ 剑气更远，「散射」→ 剑气范围更大，「**狙神**」→ 剑气更远。
- 法师的强化联动：「贯穿」→ 法球飞得更远，「散射」→ 爆炸范围更大，「**狙神**」→ 法球飞得更远，「**弹跳**」→ 法球撞墙会弹开。
- 游侠的强化联动：「贯穿」→ 子弹打穿更多敌人，「散射」→ 多发子弹，「**狙神**」→ 子弹射程更远，「**弹跳**」→ 子弹撞墙会弹开。
- 三个职业共用伤害 / 暴击 / 吸血 / 急速 等强化 ✓

### Boss（每关一只，每关造型都不同）

- **每一关都有一个 Boss**，藏在**离起点最远的大房间**里（那个房间比别的房间大一倍，19×12 格），**出口就在 Boss 房里**——想出去得先把它干掉。
- **Boss 血条只在 Boss 房里出现**，主角阵亡、进入下一关、弹强化界面时都会自动收起，不会留着上一关的状态。
- **进 Boss 房的前置条件：先清光地图上所有小怪**。小怪没清完之前，Boss 房的门是锁着的（显示暗红色，小地图上那个房间也是暗红），底部会提示「先清光地图上所有小怪，才能进入大房间挑战 Boss」。
- **Boss 房里只有 Boss 一只怪**（不会再刷小怪）——否则会死锁：小怪锁在打不开的房间里，门又要等小怪清光才开，这关就永远过不去。
- **造型轮换**：4 套专属底图轮着来，并且每轮循环会再调一次色，所以**每关看到的样子都不一样**：

  | 关卡 | Boss |
  |---|---|
  | 1 / 5 / 9 关 | 霜 冠 领 主（蓝） |
  | 2 / 6 关 | 炎 冠 君 王（橙） |
  | 3 / 7 关 | 古 木 守 卫（木色） |
  | 4 / 8 关 | 角 魔 将 军（紫） |

  Boss 造型都是**小怪没占用**的独立素材，不会和史莱姆/法师/幽灵/壮汉撞图；头上还戴一顶程序画的皇冠。
- 血量 `46 + 14×关卡数`，体型是普通怪的两倍，撞人掉 2 血。
- **「古木守卫」已重造**（不再是原版素描小人）：程序生成的 32×32 像素图 —— 树干身体、树枝手臂、发光的琥珀色眼睛、肩膀苔藓、根须底座。
- **挑战模式另有「虚空祭司」**：程序生成的骨面具 + 双角 + 紫色核心 + 悬浮碎片，三阶段三种攻击方式。
- 攻击：**环形弹幕**（12 发粉色弹丸）+ 沿路径缓速追击。攻击频率按模式分：**经典模式每 1.5 秒一轮**；**无尽模式随关卡变快**（第 1 关 2 秒 → 第 10 关 1.5 秒 → 第 20 关起 0.9 秒封顶）。
- **专属 UI**：**只有走进那个大房间才出现**——屏幕底部居中一条分段式红色血条 + Boss 名字；此时 Boss 身上那条小血条会自动藏掉，避免两条重复。右上角小地图上 Boss 房标成红色。

> **敌人会寻路**：不是直线冲过来，而是用**距离场（BFS flow field）**绕开障碍、顺着长廊追你。整张地图共用一张到主角的距离场，每 0.2 秒重算一次，开销很小。没开的房门算实心，所以别的房间的敌人会安静地等着。

> **主角先动，这关才算开始**：刚进关时敌人原地待命，不会自己扑过来。底部会提示「按 WASD / 方向键动一下 —— 这一关正式开始」，**主角动一下（或开一枪）之后敌人就恢复自由行动**（之后你站着不动，敌人照样会动）。
>
> **刷怪点离主角至少 2 格（64px）**，不会出现一进房就被贴脸的情况。

### 地图：房间 + 长廊 的迷宫

每关随机生成一张 **84×30 格（2688×960 像素）** 的大地图：

- 画面先切成 **4×2 个大格 = 8 间房（含 Boss 房）**，每格放一个**大小随机**的房间（9×11 到 17×10 格不等），再用 **2 格宽的走廊**把房间串起来（随机生成树 + 几条额外环路，所以不是死板的树）。
- 走廊走「**房间 → 格子间隙 → 房间**」：房间之间恒定留 2 格空地，走廊可以在间隙里拐个弯再进下一间房，**所以两间房的位置再随机也保证连得上**，也**不会横穿房间内部**把房间切成两半 ✓
- **每个房间都至少有一条长廊**（生成完会自动做一次连通性自检，有房间走不到就立刻补一条）✓
- **每个房间至少有 2 扇门**：只有一个门的房间是死胡同（打完怪只能原路返回），生成时会自动给它再接一条长廊 ✓
- **门口永远不会被箱子堵死**：道具不会生成在紧挨着房门的位置，生成后还会再检查一次「每个房间都走得到」，走不到就把那个房间的箱子撤掉 ✓（否则那间房里的怪杀不掉 → 小怪永远不清零 → Boss 房进不去）
- **敌人会自己绕开卡住的地方**：怪贴着箱子的斜角时会被卡住不动，所以敌人有「卡住检测」——一直靠近不了主角就**改走另一条路**绕过去 ✓（不然那间房的怪永远打不到，也就永远通不了关）
- **Boss 房不是「必经之路」**：Boss 房要等全图小怪清零才开门，所以生成时会检查「**去掉 boss 房以后其余房间还通不通**」，不通就补一条绕过 boss 房的长廊 ✓（否则有些房间只能穿过 boss 房才能到，那间房的怪永远打不到 → 整局死锁）
- 房间之间是**长廊**，走廊口有**房门**。房门规则同元气骑士：**你进到一间还有怪的房间，这间房的门就锁上（显示暗红色，出不去）；清光这间房的怪，门自动打开**。所以进房前可以自由穿行去 hunt 别的房间，但进去就得打完。
- **摄像机平滑跟随主角**（到地图边界停住），走过出口/长廊都是连续移动，不会跳。
- **敌人从关卡开始就全部存在**（每间房 2 只起，随关卡数增加），不是走到房间才刷出来；没进过的房间里它们原地待命，进了才会醒过来追你。
- **通关条件 = 击杀地图上的所有敌人**（不是"走遍所有房间"）。全图敌人清光后，离起点最远的房间墙上的**出口**开启（右上角小地图上的点变绿），走进去 → 三选一强化 → 下一关。出口**不会放在房间角落**（角落的出口玩家挤不进去，会永远触发不了），旁边也不会生成箱子，走到位就能过。
- 右上角**小地图**画的是真实布局：**不透明底板** + 房间轮廓 + 走廊 + **每扇门的状态（绿点=通，红点=锁着）** + 已清房间（绿）+ Boss 房（红框）+ 出口（红/绿点）+ 玩家（白点）。迷宫里最需要的信息就是「哪扇门能过」，所以门都单独标出来了。

## 代码结构

```
assets/
  scripts/
    Core.ts      常量、配色、瓦片地图（生成 / 碰撞 / 分轴移动）、绘图工具
    Game.ts      主组件：贴图加载、输入、主循环、玩家 / 敌人 / 子弹 / 掉落物 / HUD / 菜单 / 强化
  scenes/main.scene        Canvas + Game 组件（脚本 uuid：1a2b3c4d-5e6f-4a7b-8c9d-0e1f2a3b4c02）
  resources/knight/*.png   33 张 16x16 精灵贴图（运行时用 resources.load 按路径加载）
```

### 加新素材

1. 把 16×16 的 PNG 丢进 `assets/resources/knight/`，文件名即代码里的 key。
2. 在 `Game.ts` 顶部的 `SPRITE_KEYS` 数组里加上这个 key。
3. 需要的话在 `Core.ts` 的 `PROP_KEYS`（实心道具）里登记，或直接塞进 `MapGrid.gen` 的装饰列表。

调数值都在 `Core.ts` 顶部和 `Game.ts` 里（`WEAPONS` / `CLASSES` / `UPGRADES` 三个数组），改完直接刷新预览即可。
